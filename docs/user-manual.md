# 📖 User Manual (คู่มือการใช้งาน Chill)

ยินดีต้อนรับสู่ **Chill** — พื้นที่ 3D สำหรับการพักผ่อน ดูดาว ดื่มด่ำธรรมชาติ ตกแต่งแคมป์ และเล่นกีฬาพร้อมกับเพื่อนๆ บนเว็บเบราว์เซอร์

---

## 🎮 1. การควบคุมและคีย์ลัด (Controls & Hotkeys)

| ปุ่มกด (Key)               | ฟังก์ชันการทำงาน (Action)                                                 |
| :------------------------- | :------------------------------------------------------------------------ |
| **W, A, S, D** / **ลูกศร** | เดิน / เคลื่อนที่ตัวละคร (วิ่งอัตโนมัติเมื่อกดต่อเนื่อง)                  |
| **Spacebar**               | กระโดด (Jump) / กระโดดลอยตัวเพื่อตบวอลเลย์บอล (Spike)                     |
| **คลิกซ้าย** / **F**       | ขว้างลูกบอล (หิมะ / ทราย) / ตบวอลเลย์บอล / ยิงเป้าบิน                     |
| **คลิกขวาค้าง + ลาก**      | หมุนมุมกล้องรอบตัวละคร 360 องศา                                           |
| **Scroll Wheel**           | ซูมเข้า - ออกมุมกล้อง                                                     |
| **G**                      | ตอบโต้กับสิ่งของ (Interact) / นั่ง / จุดไฟ / ลูบหัวสัตว์เลี้ยง / เริ่มเกม |
| **Tab** หรือ **E**         | เปิด / ปิด แผงเลือกของตกแต่ง (Props Palette)                              |
| **C**                      | เปิด / ปิด แผงค้นหาและดูกลุ่มดาว (Constellations Panel)                   |
| **P**                      | เปิด / ปิด แผงเลือกสัตว์เลี้ยงคู่ใจ (Companion Pets Panel)                |
| **L**                      | เปิด / ปิด หน้าต่างแชร์ห้อง Multiplayer (LAN / Cloud Party)               |
| **T**                      | เปิดช่องพิมพ์ความคิด (Thought Lantern)                                    |
| **\ (Backslash)**          | เปิด / ปิด แผงสถิติเอนจิน (FPS / Quality Tier Stats)                      |
| **Esc**                    | ออกจากหน้าต่าง / ยกเลิกการนั่ง / ออกจากแมตช์กีฬา                          |

## 🌌 2. การดูดาวและค้นหากลุ่มดาว (Stargazing on Observatory Peak)

1. สลับฉากไปที่ **Observatory Peak (ยอดเขาหอดูดาว)** ผ่านเมนู Scenery ด้านล่าง
2. สัมผัสบรรยากาศท้องฟ้ายามค่ำคืน 360° พร้อม **ดวงจันทร์ข้างขึ้นข้างแรมตามเวลาจริงของโลก**
3. กดปุ่ม **`[C]`** หรือไอคอนกลุ่มดาวที่แถบด้านล่าง เพื่อเปิดแผงควบคุม:
   - **สวิตช์เปิด/ปิด (Toggle)**: เปิดเพื่อแสดงเส้นโยงกลุ่มดาว 88 กลุ่มและภาพวาดเทพปกรณัมคลาสสิก
   - **ค้นหากลุ่มดาว (Search)**: พิมพ์ชื่อกลุ่มดาว (เช่น _Orion_, _Ursa Major_, _Cassiopeia_) กล้องจะหันหน้าเล็งเป้าหมายไปยังกลุ่มดาวนั้นบนท้องฟ้าอัตโนมัติ
   - **ปรับความสว่าง (Opacity)**: เลื่อนแถบเพื่อปรับความคมชัดหรือความนุ่มนวลของภาพเทพปกรณัม
   - **เลือกวันที่ (Date Picker)**: เลือกดูท้องฟ้าย้อนหลังหรือในอนาคตเพื่อดูตำแหน่งดาวจริงในวันนั้นๆ

---

## 🐾 3. การเลือกและเล่นกับสัตว์เลี้ยง (Companion Pets)

1. กดปุ่ม **`[P]`** หรือคลิกไอคอนรูปสัตว์เลี้ยงที่แถบด้านล่าง
2. เลือกน้องๆ สัตว์เลี้ยงคู่ใจได้ถึง 6 ชนิด:
   - 🦊 **น้องจิ้งจอก (Fox)**
   - 🐱 **น้องแมว (Cat)**
   - 🐶 **น้องหมา (Dog)**
   - 🐧 **น้องเพนกวิน (Penguin)**
   - 🐰 **น้องกระต่าย (Rabbit)**
   - 🐹 **น้องแฮมสเตอร์ (Hamster)**
3. **ตั้งชื่อสัตว์เลี้ยง**: พิมพ์ชื่อที่ต้องการ ป้ายชื่อ 3D ลอยตัวจะปรากฏเหนือหัวน้อง
4. **ลูบหัว (Petting)**: เดินเข้าไปใกล้น้องแล้วกด **`[G]`** น้องจะกระโดดหมุนตัวดีใจพร้อมหัวใจลอยรอบตัว

---

## 🪧 4. การวางของตกแต่งและป้ายคำคม Real-time

1. กด **`[Tab]` หรือ `[E]`** เพื่อเปิดแผงเลือกของตกแต่ง
2. กดตัวเลข **`1` ถึง `0`** เพื่อวางสิ่งของลงตรงหน้าตัวละคร
3. **ป้ายบิลบอร์ดคำคมประจำวัน (`[B] Daily Billboard`)**:
   - ป้ายบิลบอร์ดไม้ขนาดใหญ่ 3D พร้อมไฟส่องสว่าง
   - เดินเข้าไปใกล้แล้วกด **`[G]`** เพื่อเปิดหน้าต่างสุ่มคำคมสำหรับ **คนทำงาน & วัยรุ่น** (4 หมวดหมู่)
   - สามารถพิมพ์แก้ไขข้อความเอง หรือกดสุ่มใหม่ ข้อความบนป้าย 3D จะอัปเดตแบบ Real-time ให้เพื่อนทุกคนในห้องเห็นทันที!
4. **ป้ายข้อความ (`[3] Signpost`)**:
   - พิมพ์ข้อความภาษาไทยหรืออังกฤษ หรือกดปุ่ม **`✨ AI กลอน`** เพื่อให้ In-Browser AI ช่วยแต่งกลอนไฮกุตามบรรยากาศของฉากนั้นๆ

## 🏐 5. การเล่นกีฬาและมินิเกม

1. สลับไปที่ **Sunset Sports Arena**:
2. **วอลเลย์บอลชายหาด (Volleyball)**:
   - เดินเข้าฝั่งซ้ายกด **`[G] Join Team Red`** หรือฝั่งขวากด **`[G] Join Team Blue`**
   - แข่งขัน 5 คะแนน กด **`Spacebar + [F]`** เพื่อกระโดดตบบอล (Spike)
3. **แข่งยิงเป้าบิน (Skeet Shooting)**:
   - เดินเข้าแท่นยิงฝั่งตะวันตก กด **`[G] Start Shootout (10 Waves)`**
   - เล็งและ **คลิกซ้าย** เพื่อปาลูกกระสุนทรายดักจานเป้าบินสีส้มกลางอากาศ

---

## 🌐 6. การเปิดห้อง Multiplayer และแชร์ลิงก์

1. กดปุ่ม **`[L]`** เพื่อเปิดหน้าต่าง **LAN Multiplayer**
2. ตั้งชื่อห้อง (เช่น _Stargazing Night_) แล้วกด **Start hosting**
3. คัดลอกลิงก์ที่ระบบสร้างให้ ส่งให้เพื่อนเปิดบนเบราว์เซอร์
4. เพื่อนจะ **Auto-join** เข้ามายืนในโลก 3D เดียวกันทันที พร้อม Sync ตำแหน่ง ท่าทาง แชท และฉากโลกอัตโนมัติ!

## ☁️ 7. การ Deploy ขึ้น Google Cloud Platform (GCP)

Chill รองรับการ Deploy เป็น **Single Unified Container** ขึ้นบน **Google Cloud Run** ด้วยคำสั่งเดียว:

```bash
# รันคำสั่ง deploy ผ่าน gcloud CLI
./scripts/deploy-gcp.sh <YOUR_GCP_PROJECT_ID> asia-southeast1
```

ระบบจะสร้าง URL สาธารณะบน Cloud Run ให้เข้าใช้งานทั้งเว็บ 3D และ Multiplayer ได้ทันทีครับ!
