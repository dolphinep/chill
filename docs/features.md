# ✨ Chill Feature Specifications

Chill combines cozy environment simulation, astronomical stargazing, companion pets, sandbox prop placement, and real-time multiplayer casual sports into one unified WebGPU world.

---

## 🌄 1. Five Diverse Sceneries (ทิวทัศน์ 5 สไตล์)

| Scenery                    | Theme & Environment              | Unique Visual & Physics Features                                                                                   |
| :------------------------- | :------------------------------- | :----------------------------------------------------------------------------------------------------------------- |
| **❄️ Frostholm Ridge**     | ยอดเขาหิมะแถบนอร์ดิก             | รอยย่ำเท้าบนหิมะที่กดลึกแบบ Real-time, ลมหนาวสังเคราะห์, สกีลงเขา, และกองไฟอุ่นๆ                                   |
| **🌊 Kamakura Bay**        | ชายหาดและเกาะสไตล์ญี่ปุ่น        | คลื่นทะเลกระทบหาดทราย, ทรายนุ่มที่เกิดรอยเท้า, ต้นซากุระพลิ้วไหว, และโคมไฟลอยน้ำ                                   |
| **🍁 Aki Highlands**       | ทุ่งหญ้าและเนินเขาฤดูใบไม้ร่วง   | บรรยากาศอบอุ่น, นกบินผ่านท้องฟ้า, ธรรมชาติอันเงียบสงบ และใบไม้แดงปลิวไหว                                           |
| **🌅 Sunset Sports Arena** | ลานกีฬาชายหาดยามพระอาทิตย์ตก     | ลานราบสำหรับเล่นกีฬา, สนามวอลเลย์บอลชายหาด, และสนามแข่งยิงเป้าบิน Skeet Shooting                                   |
| **🌌 Observatory Peak**    | ยอดเขาหอดูดาวและท้องฟ้ายามค่ำคืน | ท้องฟ้าดูดาวลึก 360°, ดวงจันทร์ข้างขึ้นข้างแรมตามเวลาจริงในดาราศาสตร์, 88 กลุ่มดาวจริงของ IAU, และ 85 ภาพเทพปกรณัม |

## 🌌 2. Real Astronomical Sky & Constellations (ระบบดาราศาสตร์ & ท้องฟ้าจำลองจริง)

1. **🌒 Real Moon Phase (ดวงจันทร์ข้างขึ้นข้างแรมตามจริง)**:
   - คำนวณตำแหน่งและเสี้ยวพระจันทร์ตามวันและเวลาจริงของโลก ด้วย `astronomy-engine`
   - แรเงาเส้นแบ่งมืด-สว่าง (Astronomical Terminator Curve) อย่างแม่นยำ พร้อมออร่าแสงจันทร์เรืองรอง (Ethereal Moon Glow) นุ่มนวล
2. **⭐ 88 IAU Constellations (กลุ่มดาวสากล 88 กลุ่ม)**:
   - จำลองตำแหน่งดาวฤกษ์ 5,044 ดวงจาก Hipparcos Star Catalog (ความสว่าง mag ≤ 6)
   - เส้นเชื่อมกลุ่มดาวจริงทั้ง 88 กลุ่มตามมาตรฐานสหพันธ์ดาราศาสตร์สากล (IAU)
3. **🎨 85 Mythological Illustrations (ภาพวาดเทพปกรณัมดั้งเดิม)**:
   - ภาพประกอบเทพปกรณัมคลาสสิกโดย Johan Meuris จากโปรเจกต์ Stellarium Planetarium
   - ดึงและวาร์ปภาพเข้ากับตำแหน่งดาวจริงด้วยอัลกอริทึม Affine Grid Barycentric Warping
4. **🔍 Interactive Constellation Modal (แผงควบคุมและค้นหากลุ่มดาว)**:
   - ค้นหากลุ่มดาวพร้อมระบบหมุนกล้องเล็งเป้าหมายอัตโนมัติ (Camera Auto-focus)
   - ปรับความโปร่งแสงของภาพประกอบ (Opacity Slider) และปุ่มเปิด/ปิด (Default: ปิด เพื่อดูดาวยามค่ำคืนอย่างเป็นธรรมชาติ)
   - เลือกดูท้องฟ้าย้อนหลังหรือล่วงหน้าได้ตามวันที่ต้องการ (Date Picker)

## 🐾 3. Companion Pets (ระบบสัตว์เลี้ยงแสนน่ารัก 6 ชนิด)

ผู้เล่นสามารถเลือกสัตว์เลี้ยงคู่ใจมาเดินเคียงข้างในโลก 3D ได้จากแผงสลับสัตว์เลี้ยง:

| สัตว์เลี้ยง                    | ลักษณะและแอนิเมชัน                                  |
| :----------------------------- | :-------------------------------------------------- |
| **🦊 Fox (น้องจิ้งจอก)**       | วิ่งดุ๊กดิ๊ก หางฟู ขี้เล่นและอยากรู้อยากเห็น        |
| **🐱 Cat (น้องแมว)**           | เดินเยื้องย่างอย่างสง่างาม ชอบนั่งคลอเคลีย          |
| **🐶 Dog (น้องหมา)**           | ร่าเริง วิ่งตามเจ้าของอย่างกระตือรือร้นและซื่อสัตย์ |
| **🐧 Penguin (น้องเพนกวิน)**   | เดินเตาะแตะ ปีกกระพือ น่ารักน่าเอ็นดู               |
| **🐰 Rabbit (น้องกระต่าย)**    | กระโดดดึ๋งๆ หูยาวกระดิกตามเสียงลม                   |
| **🐹 Hamster (น้องแฮมสเตอร์)** | ตัวกลมจิ๋ว วิ่งไว ขยับดุ๊กดิ๊กตลอดเวลา              |

- **การตอบโต้**: เดินเข้าไปใกล้กด **`[G]`** เพื่อลูบหัว (Petting Reaction) น้องจะกระโดดหมุนตัวดีใจพร้อมเอฟเฟกต์หัวใจลอยรอบตัว
- **การตั้งชื่อ**: สามารถตั้งชื่อสัตว์เลี้ยงได้ตามใจชอบ ป้ายชื่อ 3D จะลอยอยู่เหนือหัวน้อง

## 🪑 4. Interactive Props & Daily Billboard

1. 🔥 **Campfire (แคมป์ไฟ)**: จุดไฟหรือดับไฟได้ มีประกายไฟ ลอยควัน และเสียงฟืนปะทุ
2. 🏮 **Lantern (โคมไฟญี่ปุ่น)**: เปิด/ปิดไฟโทนอบอุ่นยามค่ำคืน
3. 🪵 **Bench (ม้านั่งไม้)**: นั่งพักผ่อน (ตัวละครจะยกตัวขึ้นนั่งบนเบาะเก้าอี้อย่างสมจริง)
4. ⛺ **Cozy Tent (เต็นท์พักแรม)**: มุดเข้าไปนั่งชิลล์ในเต็นท์พร้อมแสงไฟละมุน
5. ☕ **Tea Table (โต๊ะน้ำชาญี่ปุ่น)**: มีเบาะรองนั่ง 2 ฝั่ง สามารถนั่งจิบชาพร้อมกันได้ 2 คน
6. 🌸 **Sakura Pot (กระถางซากุระบอนไซ)**: กระถางต้นซากุระพร้อมเอฟเฟกต์กลีบดอกไม้โปรยปราย
7. 🎆 **Firework (แท่นจุดพลุ)**: กดจุดเพื่อยิงบั้งไฟขึ้นไประเบิดเป็นประกายสีสันบนท้องฟ้า
8. 🪧 **Custom Signpost (ป้ายข้อความ)**: พิมพ์ข้อความภาษาไทยหรืออังกฤษ 1 ประโยค ป้ายจะปักลงพื้นและแสดงข้อความ 3D ให้ทุกคนเห็น (พร้อมปุ่ม `✨ AI กลอน`)
9. 📜 **Daily Quote Billboard (บิลบอร์ดคำคมประจำวัน)**: ป้ายบิลบอร์ดไม้ 3D ขนาดใหญ่ สุ่มคำคมคนทำงานและวัยรุ่น ซิงค์แบบ Real-time ข้ามผู้เล่นทุกคนในห้อง

10. **🌐 Thought Lantern & Chat Translator (แปลภาษาโคมไฟและแชท)**:
    - เมื่อเพื่อนต่างชาติพิมพ์ข้อความในแชทห้อง LAN หรือปักป้ายข้อความภาษาอื่น
    - มีปุ่ม **`🌐 แปล (Translate)`** ช่วยแปลข้อความเป็นภาษาไทยหรืออังกฤษได้ทันทีด้วย In-Browser Translation API

## 🏐 4. Sports & Minigames (ระบบกีฬาและมินิเกม)

### 1. 🏐 Beach Volleyball (วอลเลย์บอลชายหาด)

- **ตำแหน่ง**: ใจกลาง `Sunset Sports Arena` (พิกัด `0, 0`)
- **การแบ่งทีม**: เดินเข้าฝั่งซ้ายกด **`[G] Join Team Red 🔴`** หรือเดินเข้าฝั่งขวากด **`[G] Join Team Blue 🔵`**
- **การแข่งขัน**: เล่น 1 เซ็ต 5 คะแนน เสิร์ฟบอลแรกข้ามตาข่ายอัตโนมัติ
- **Kinematics & Spikes**:
  - Auto-bump รับบอลส่งกลับข้ามตาข่ายเมื่อวิ่งเข้าไปใกล้ลูกบอล
  - กด **`Spacebar` กระโดดขึ้นกลางอากาศ แล้วกด `[F]`** เพื่อกระโดดตบบอล (Spike) อย่างรวดเร็ว
  - ผู้เล่นทุกคนจะเห็นท่าทางเหวี่ยงแขนตบบอลของฝั่งตรงข้ามแบบ Real-time
- **Auto-Stop on Leave**: หากมีผู้เล่นออกจากห้องหรือกด `[Esc] Leave` เกมจะหยุดและรีเซ็ตสนามทันที

### 2. 🎯 Skeet / Clay Pigeon Shooting (แข่งยิงเป้าบิน)

- **ตำแหน่ง**: ฝั่งตะวันตกของ `Sunset Sports Arena` (พิกัด `-24, 0`)
- **การเริ่มรอบ**: เดินเข้าแท่นยืนยิงแล้วกด **`[G] Start Shootout (10 Waves)`**
- **ฟิสิกส์และการยิง**:
  - เครื่องยิง Trap Box จะดีดจานเป้าบินสีส้มนีออนพุ่งโค้งขึ้นสู่ท้องฟ้าทีละ 1-2 เป้า
  - ผู้เล่นใช้การ **คลิกซ้าย หรือกด `[F]`** เพื่อปาลูกกระสุนทรายเล็งดักเป้าบินกลางอากาศ
  - เมื่อปาโดน จานเป้าจะ **แตกกระจายเป็นสะเก็ดอนุภาคสีส้ม (12 Fragments Burst)** พร้อมเสียงแตก และบวกคะแนน
  - กระดานไฟ 3D และ HUD สรุปผลความแม่นยำ (Accuracy %) เมื่อครบ 10 Waves

### 3. 🏹 Target Practice (ยิงเป้าไม้ล้ม)

- **ตำแหน่ง**: ฝั่งตะวันออกของ `Sunset Sports Arena` (พิกัด `22, 0`)
- ปาลูกบอลใส่เป้าไม้เพื่อให้ล้มลง เมื่อล้มครบทุกเป้าจะเริ่มนับเวลารีเซ็ตตั้งขึ้นใหม่เอง

## 🌐 4. Multi-Room Multiplayer Networking

- **Multi-Room Isolation**: แยกห้องแบบ 100% ผ่าน URL Parameter `?room=ชื่อห้อง` เช่น `?room=camp` และ `?room=sports`
- **Anti-Ghost Eviction**: ป้องกันตัวละครผีค้างเมื่อกด Refresh หน้าจอ โดยตัด Connection เก่าทันที
- **Floating Thought Lanterns (โคมไฟความคิดลอยน้ำ)**: กด `[T]` เพื่อพิมพ์ความคิด ข้อความจะลอยขึ้นฟ้าเป็นโคมไฟ 3D และส่งเข้าช่องแชท

---

## 🎵 5. Generative Lo-fi & Procedural Audio

- **Endless Generative Music**: สังเคราะห์เพลง Lo-fi สดผ่าน Web Audio API ตาม Mood ต่างๆ ไม่มีวันซ้ำ
- **Procedural Ambience**: สังเคราะห์เสียงธรรมชาติแบบเรียลไทม์ (คลื่นทะเล, ลมพัดยอดเขา, นกร้อง)
